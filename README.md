# 💻 Sistema de Préstamo y Reserva de Salas - Centro TIC

Aplicación para la gestión, actualización y consulta de reservas de salas de cómputo, docentes, programas académicos, cursos y aplicaciones.

---

## 🗄️ Estructura de la Base de Datos

El sistema maneja las siguientes entidades principales:
* **Salas de cómputo**
* **Docentes y Cursos**
* **Reservas y Horarios**
* **Aplicaciones y Programas Académicos**

---

## 🛠️ Tecnologías Utiliadas

* **Base de Datos:** PostgreSQL (o el SGBD que estés usando)
* **Control de Versiones:** Git & GitHub

---

## 📁 Estructura del Proyecto

* `/database`: Scripts de creación de tablas, relaciones y datos de ejemplo.
* `/docs`: Diagrama Entidad-Relación y documentación.
